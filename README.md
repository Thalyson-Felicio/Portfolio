# Portfólio de Thalyson Felicio

Portfólio pessoal desenvolvido para apresentar estudos, projetos web e a trajetória de formação em Engenharia de Software.

## Sobre o projeto

A aplicação apresenta uma página inicial com hero, navegação responsiva, áreas de desenvolvimento, resumo de projetos e formação. O conteúdo atual está em evolução junto com o portfólio profissional.

## Tecnologias

- Next.js `16.0.3`
- React `19.2.0`
- TypeScript
- Tailwind CSS
- React Icons
- tsParticles
- Typewriter Effect

## Estrutura

```text
.
├── app/                  # entrada da aplicação e metadados
├── components/Home/      # hero, navegação, serviços e resumo
├── constant/             # configurações de navegação
└── public/               # imagens e arquivos estáticos
```

## Como executar

Pré-requisito: Node.js compatível com as versões das dependências do projeto.

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000`.

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run start`: inicia a aplicação compilada.
- `npm run lint`: executa o ESLint.

## Status

Projeto em desenvolvimento. A interface já possui a estrutura principal de apresentação, mas alguns conteúdos e links continuam sendo refinados.
